# 🛍️ Zenith Store - Boutique E-commerce Dropshipping

Boutique e-commerce moderne avec dropshipping AliExpress automatise et paiements Stripe.

## 🚀 Installation

```bash
# 1. Cloner le repo
git clone https://github.com/votre-username/zenith-store.git
cd zenith-store

# 2. Installer les dependances
npm install

# 3. Configurer l'environnement
cp .env.example .env
# Editer .env avec vos cles API

# 4. Lancer le serveur
npm start
```

## 📋 Fonctionnalites

- ✅ Paiements Stripe (CB + Apple Pay)
- ✅ Dropshipping AliExpress automatise
- ✅ Panel admin complet
- ✅ Support chat temps reel
- ✅ Gestion commandes
- ✅ 21+ fonctionnalites e-commerce
