ZENITH STORE

Politique de Confidentialité

Dernière mise à jour : Octobre 2026

Introduction

Zenith Store s'engage à protéger la vie privée de ses utilisateurs. Cette politique de confidentialité explique quelles données nous collectons, pourquoi nous les collectons et comment nous les utilisons.

Données Collectées

Nous collectons les données suivantes :
• Données d'identification : nom, prénom, email, téléphone
• Données de commande : adresse de livraison, historique d'achats
• Données de navigation : adresse IP, cookies, pages visitées
• Données de paiement : traitées de manière sécurisée par nos prestataires de paiement

Utilisation des Données

Vos données sont utilisées pour :
• Traiter et livrer vos commandes
• Gérer votre compte client
• Vous envoyer des informations sur vos commandes
• Améliorer nos services
• Vous proposer des offres personnalisées (avec votre consentement)

Base Légale

Nous collectons et traitons vos données sur les bases légales suivantes :
• Exécution du contrat : traitement de vos commandes
• Obligations légales : facturation, comptabilité
• Intérêt légitime : amélioration de nos services
• Consentement : marketing, newsletters

Conservation des Données

Vos données sont conservées pendant :
• Données de compte : jusqu'à la suppression de votre compte
• Données de commande : 10 ans (obligations légales)
• Données de navigation : 13 mois maximum

Vos Droits

Conformément au RGPD, vous disposez des droits suivants :
• Droit d'accès : consulter vos données
• Droit de rectification : corriger vos données
• Droit à l'effacement : supprimer vos données
• Droit d'opposition : refuser le traitement de vos données
• Droit à la portabilité : récupérer vos données
Pour exercer ces droits, contactez-nous à : support@zenithstore.com

Sécurité

Nous mettons en œuvre des mesures techniques et organisationnelles appropriées pour protéger vos données contre tout accès non autorisé, perte ou destruction. Les paiements sont sécurisés via des protocoles de cryptage SSL.

Cookies

Notre site utilise des cookies pour :
• Mémoriser votre panier
• Analyser le trafic (Google Analytics)
• Améliorer votre expérience
Vous pouvez gérer vos préférences de cookies dans les paramètres de votre navigateur.

Partage des Données

Vos données ne sont jamais vendues à des tiers. Nous les partageons uniquement avec :
• Nos prestataires de paiement (transactions sécurisées)
• Nos transporteurs (livraison)
• Nos prestataires techniques (hébergement, maintenance)

Contact

Pour toute question concernant cette politique de confidentialité ou pour exercer vos droits, contactez-nous à : support@zenithstore.com
